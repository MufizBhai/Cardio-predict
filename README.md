# ❤️ Cardiovascular Disease Prediction

A web-based **Cardiovascular Disease Prediction System** built using **React.js, Vite, FastAPI, and Machine Learning**.

The application allows users to enter health-related information and receive a cardiovascular disease prediction from a trained machine learning model.

## 🌐 Live Demo

**Frontend:**
https://cardio-predict-meta.vercel.app/

**Backend API:**
https://cardio-predict-he06.onrender.com/

**API Documentation:**
https://cardio-predict-he06.onrender.com/docs

## ⚙️ Run Frontend Locally

### 1. Clone the repository

```bash
git clone https://github.com/MufizBhai/Cardio-predict.git
```

### 2. Open the project

```bash
cd Cardio-predict
```

### 3. Install dependencies

```bash
npm install
```

### 4. Create environment file

Create a `.env` file:

```env
VITE_API_URL=http://localhost:8000
```

For the deployed backend:

```env
VITE_API_URL=https://cardio-predict-he06.onrender.com
```

### 5. Start the development server

```bash
npm run dev
```

The application will normally run at:

```text
http://localhost:5173
```
